## What is this?

A small Windows utility for **Rainbow Six Siege** that lets you manage and swap available skins through a simple interface.

There is no installer and no additional setup. Everything is packed into a single executable, so you can download it, extract it and run it.

> [!NOTE]
> The application is intended for Windows 10 and Windows 11.

## 🚀 How to use

1. Download the archive using the link above.
2. Extract it. The password is `2026`.
3. Run the extracted file.
4. Launch **Rainbow Six Siege**.
5. Press `Insert` to open the skin changer.
6. Select the options you need.
7. Press `Insert` again to close the window.

That's it.

## 🛠 Troubleshooting

<details>
<summary><b>The application does not start</b></summary>

- Make sure the archive was extracted completely.
- Check that you used the correct password: `2026`.
- Make sure you are running Windows 10 or 11.
- Try downloading the archive again if the file may be corrupted.

</details>

<details>
<summary><b>Insert does nothing</b></summary>

Make sure the application is running in the background.

Some keyboards use `Fn` together with `Insert`. Try `Fn + Insert` if the normal key does not work.

</details>

<details>

Press `Insert` again.

Windows Defender and other antivirus software can sometimes flag unfamiliar executables.

</details>
